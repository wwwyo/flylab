# 最初の PoC は loom-escape（2026-09-23）

- Status: Accepted
- Date: 2026-09-23

視覚の looming 検出（LC4 / LPLC2）→ 逃避指令ニューロン（DNp01 = giant fiber）の回路を全グラフの配線で通す最小実験。確かめるのは (1) 静息時に descending neuron が ~1Hz で保たれるか、(2) 片側の LC4/LPLC2 への電流注入で同側 DNp01 が先に発火し、対側は沈黙または遅延するか（ipsilateral 伝播）、(3) 逃避系以外の descending cell type を巻き込まないか。**通ることは「配線が機能的か」の十分条件ではなく、信号が届くことの確認に留まる**と docs に明記した
